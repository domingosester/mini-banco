# Mini Banco

O projeto “Mini Banco” mostra a lógica de um sistema bancário onde a pessoa pode registrar seu nome. O projeto contém um menu onde o usuário pode consultar o saldo, sacar, depositar, ver o extrato e encerrar o sistema com a opção de sair. Resolvendo problemas como controles de finanças, ajudando a administrar o dinheiro podendo ver oque entra e o que sai da conta.

## 🚀 Funcionalidades
- Cadastro de clientes e contas.
- Registro de transações bancárias (depósito, saque).
- Geração de relatórios associados ao titular da conta (consultar saldo e ver extrato).
